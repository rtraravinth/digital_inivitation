# Per-Link Icons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every link an icon, derived from its address so pasting `instagram.com/name` shows the Instagram mark unprompted, with a stored override for when the guess is wrong.

**Architecture:** One new module, `src/lib/icons.tsx`, owns the icon set, the hostname map, the resolver and the render component. `LinkItem` gains an optional `icon` field that only ever means "override the guess". The backend accepts that field first, because `LinkItem` is a `StrictCamelModel` with `extra="forbid"` and would 422 an editor that sent it early. Rendering then lands almost entirely in the two shared components every theme already goes through.

**Tech Stack:** Next.js 16.3.2, React 19.2.8, Tailwind CSS 4, FastAPI on PostgreSQL, pytest. No new runtime dependency: brand paths are extracted once from `simple-icons` installed with `--no-save`, and the package is removed again.

**Spec:** `docs/superpowers/specs/2026-09-07-link-icons-design.md`

## Global Constraints

- **Zero border radius anywhere.** `--radius-*` is `0` on purpose.
- **Every colour from a token.** Icons take `currentColor` and never name a colour of their own.
- **No new runtime dependency.** `package.json` must still list exactly `next`, `react`, `react-dom` when this is done.
- **`iconFor` must never throw.** It runs during render in every theme, and the editor writes a partial URL on every keystroke.
- **Hostname matching is on the registrable domain** — hostname equal to the suffix, or ending in `"." + suffix`. Never a substring test.
- **`icon` is optional** — `icon?: string` in TypeScript, `icon: str = Field(default="", max_length=32)` on the API. Absent means "decide from the address". `normalize()` leaves it alone.
- **`LinkItem` is a `StrictCamelModel`** (`backend/app/schemas/common.py:25`, `extra="forbid"`), so an unknown key is a 422, not a silent drop. The backend field lands before anything sends it.
- **The API is camelCase on the wire.** No mapping layer.
- **There is no frontend test runner.** The gate for a frontend task is `npm run lint`, `npm run build` with the dev server stopped, and the named manual checks. Backend tasks use real pytest TDD.
- Backend test command: `cd backend && .venv/bin/python -m pytest`. 269 tests pass today.

```tsx
 * Link icons.
 *
 * The brand marks are Simple Icons (https://simpleicons.org), CC0, copied in
 * as path data rather than added as a dependency: this project has three, the

/**

 */

  ["x.com", "x"],
  ["twitter.com", "x"],
  ["facebook.com", "facebook"],
  ["fb.me", "facebook"],
  ["tiktok.com", "tiktok"],
  ["threads.net", "threads"],
  ["threads.com", "threads"],
  ["github.com", "github"],
  ["gitlab.com", "gitlab"],
  ["behance.net", "behance"],
  ["dribbble.com", "dribbble"],
  ["figma.com", "figma"],
  ["medium.com", "medium"],
  ["substack.com", "substack"],
  ["notion.so", "notion"],
  ["notion.site", "notion"],
  ["spotify.com", "spotify"],
  ["soundcloud.com", "soundcloud"],
  ["vimeo.com", "vimeo"],
  ["twitch.tv", "twitch"],
  ["discord.com", "discord"],
  ["discord.gg", "discord"],
  ["t.me", "telegram"],
  ["telegram.org", "telegram"],
  ["bsky.app", "bluesky"],
  ["calendly.com", "calendar"],
  ["cal.com", "calendar"],
];

function isIconId(value: string): value is IconId {
  return Object.prototype.hasOwnProperty.call(ICONS, value);
}

/**
 * The icon a link shows: its stored override when it names one this build
 * knows, otherwise whatever the address says, otherwise the generic glyph.
 *
 * Never throws. It runs during render in every theme, and the editor writes a
 * half-typed address on every keystroke — `new URL()` would throw on most of
 * them.
 */
export function iconFor(link: { url: string; icon?: string }): IconId {
  const override = link.icon?.trim() ?? "";
  if (override && isIconId(override)) return override;

  const raw = link.url.trim();
  if (!raw) return "link";
  const lower = raw.toLowerCase();
  if (lower.startsWith("mailto:") || (raw.includes("@") && !raw.includes("/"))) {
    return "email";
  }
  if (lower.startsWith("tel:")) return "phone";

  let host = "";
  try {
    const withScheme = /^https?:\/\//i.test(raw) ? raw : `https://${raw.replace(/^\/+/, "")}`;
    host = new URL(withScheme).hostname.toLowerCase().replace(/^www\./, "");
  } catch {
    return "link";
  }

  for (const [suffix, id] of HOSTS) {
    if (host === suffix || host.endsWith(`.${suffix}`)) return id;
  }
  return "link";
}

/** One glyph, inheriting the surrounding colour. */
export function LinkIcon({
  id,
  size = 16,
  style,
}: {
  id: IconId;
  size?: number;
  style?: CSSProperties;
}) {
  const def: IconDef = ICONS[id];
  return (
    <svg
      width={size}
      height={size}
      viewBox="0 0 24 24"
      aria-hidden
      focusable="false"
      className="flex-none"
      style={style}
    >
      <path d={def.path} {...(def.kind === "fill" ? { fill: "currentColor" } : STROKE)} />
    </svg>
  );
}
```

- [ ] **Step 1: Write `IconSelect`**

Create `src/components/IconSelect.tsx`. It follows `src/components/builder/FontSelect.tsx`: a trigger button, and a panel that **closes on a backdrop element rather than a `document` listener**.

```tsx
"use client";

import { useState } from "react";
import { ICONS, ICON_LIST, LinkIcon, iconFor, type IconId } from "@/lib/icons";
import type { LinkItem } from "@/lib/types";

/**
 * The icon for one link. The first entry is always Automatic, which shows
 * whatever the address currently resolves to — choosing it stores "", which
 * is how an override is undone.
 *
 * Closes on a backdrop rather than a listener on `document`, matching
 * `FontSelect`: a listener there is the thing that breaks the moment a panel
 * is opened over an iframe.
 */
export function IconSelect({
  link,
  onChange,
}: {
  link: LinkItem;
  onChange: (icon: string) => void;
}) {
  const [open, setOpen] = useState(false);
  const [query, setQuery] = useState("");
  const resolved = iconFor(link);
  const overridden = Boolean(link.icon);

  const shown = query.trim()
    ? ICON_LIST.filter((id) => {
        const q = query.trim().toLowerCase();
        return id.includes(q) || ICONS[id].name.toLowerCase().includes(q);
      })
    : ICON_LIST;

  function pick(icon: string) {
    onChange(icon);
    setOpen(false);
    setQuery("");
  }

  return (
    <div className="relative">
      <button
        type="button"
        className="btn btn-secondary btn-icon"
        aria-haspopup="listbox"
        aria-expanded={open}
        aria-label={`Icon: ${overridden ? ICONS[resolved].name : `${ICONS[resolved].name}, automatic`}`}
        onClick={() => setOpen((v) => !v)}
      >
        <LinkIcon id={resolved} />
      </button>

      {open && (
        <>
          <div className="fixed inset-0 z-20" onClick={() => setOpen(false)} />
          <div
            className="absolute left-0 z-30 mt-1 w-[260px] p-2"
            style={{
              background: "var(--color-surface)",
              border: "2px solid var(--color-ink)",
            }}
          >
            <input
              className="input mb-2 w-full"
              value={query}
              placeholder="Search icons"
              aria-label="Search icons"
              onChange={(e) => setQuery(e.target.value)}
            />
            <div className="grid max-h-[220px] grid-cols-4 overflow-y-auto">
              {!query.trim() && (
                <button
                  type="button"
                  className="col-span-4 flex cursor-pointer items-center gap-2 px-2 py-2 text-left text-xs"
                  style={{
                    borderBottom: "1px solid var(--color-divider)",
                    color: overridden ? "inherit" : "var(--color-accent)",
                  }}
                  onClick={() => pick("")}
                >
                  <LinkIcon id={resolved} />
                  Automatic — {ICONS[resolved].name}
                </button>
              )}
              {shown.map((id) => (
                <button
                  key={id}
                  type="button"
                  title={ICONS[id].name}
                  aria-label={ICONS[id].name}
                  className="flex cursor-pointer flex-col items-center gap-1 px-1 py-2 text-[10px]"
                  style={{ color: link.icon === id ? "var(--color-accent)" : "inherit" }}
                  onClick={() => pick(id)}
                >
                  <LinkIcon id={id} size={20} />
                  <span className="w-full truncate text-center">{ICONS[id].name}</span>
                </button>
              ))}
            </div>
          </div>
        </>
      )}
    </div>
  );
}
```
